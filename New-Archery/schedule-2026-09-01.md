## 5. Tech / gotchas noted

- App: `http://localhost:8991`
- Python change → `docker restart customarcherysec`; template-only change → `docker cp` only
- App takes ~40-60s to come up after restart (poll `/auth/login/` until 200)
- **BOM gotcha:** the `write` tool / `Set-Content -Encoding UTF8` add a UTF-8 BOM that breaks Django shell scripts — write raw bytes via `[System.IO.File]::WriteAllText(..., New-Object Text.UTF8Encoding($false))`
- Run Django queries via `docker cp` script to `/tmp` then `python manage.py shell < /tmp/x.py`
